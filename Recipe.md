# Media Radio Crafting Recipes

This file documents the in-game recipes for all Media Radio items.

## Antena

Output: `mediaradio:antena` x1

Pattern:

```text
I
C
E
```

Keys:

- `I` = Iron Ingot
- `C` = Copper Ingot
- `E` = Ender Pearl

## Display

Output: `mediaradio:display` x1

Pattern:

```text
G G G
D R D
G G G
```

Keys:

- `G` = Glass
- `D` = Green Dye
- `R` = Redstone

## Media Radio

Output: `mediaradio:radio` x1

Pattern:

```text
  A
D B I
S I S
```

Keys:

- `A` = Antena
- `D` = Display
- `B` = Iron Block
- `I` = Iron Ingot
- `S` = Stone Button
