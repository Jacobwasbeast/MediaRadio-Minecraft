# Media Radio

Bring a fully interactive media radio into Minecraft.

Media Radio adds a radio item that can be used handheld or placed as a block, with queue controls, playlist tools, source import flows, and real-time in-world media status rendering.

## Highlights

- Handheld + placeable radio in one item
- Offhand and main-hand support with dedicated poses
- Directional 3D audio for placed radios
- Real-time playback controls: prev, pause/resume, next, stop
- Seek bar, volume controls, shuffle, and loop modes
- Queue + playlist workflows
- Playlist import UI (YouTube / Global / Invites)
- Thumbnail support in queue/library/now-playing/overlays

## Usage

1. Craft a radio.
2. Right click to open the radio UI in handheld mode.
3. Shift + right click to toggle place mode.
4. Place the radio block to play in world-space audio.
5. Shift + right click the block to pick it back up.
